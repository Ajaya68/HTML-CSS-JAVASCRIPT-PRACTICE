What is JavaScript
==================
    - it is used to create interactive web pages.
        [means it makes websites respond to user actions. 
        For example:
            Clicking a button
            Showing or hiding content
            Validating forms
            Displaying pop-up messages
            Creating animations and sliders]

    - it is also known as scripting language.
        [scripting language - means a small program that require another program for execution]

    - it is also known as dynamic language.
        [dynamic means datatype of a variable is known by what type of value it holds.]

    - it supports both client and server side rendering.
        [framework/library - react.js angular.js, vue.js.....]
        [Backend-technology - Node.js, Express.js]

    - The browser will understand only JS.

History of JavaScript:
======================
- In 1995: JavaScript was created by Brendan Eich at Netscape Communications.
- It was developed in just 10 days for the Netscape Navigator web browser.
- It was first named Mocha, then renamed LiveScript, and finally JavaScript.
- The name JavaScript was chosen mainly for marketing because Java was very popular at the time 
even though JavaScript and Java are different languages.
- 1997: JavaScript was standardized by ECMA International. The standard is called ECMAScript.
- Today, JavaScript is supported by all major web browsers and is used for front-end, back-end (using Node.js), mobile, desktop, and game development.

JavaScript Engine:
==================
A JavaScript engine is a software program that reads, interprets, compiles, and executes JavaScript code by converting it into machine code that the computer can understand.


Tokens
=======
    - it is the smallest individual unit is known as Tokens.

KeyWords
========
    - keywords means the pre-defined words that are already declared and have special functionality and it should be in lowercase.

identifier
==========
    - identifier is used for identification purpose to giving name to the variable, function, clases etc..
    - there are some rules to write identifier
        i. keywords will not be the identifier.
        ii. identifier will not start with the number but 2nd position onword allows.
        iii. it will not accept any speacial character except "$", "_".
        iv. it will not accept space in between the identifier name.

literals
========
    - it is the direct value written inside code or passed by the user.
