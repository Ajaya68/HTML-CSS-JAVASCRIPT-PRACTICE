# Variables

> A **variable** is a named block of memory which is used to store a value.

We create a variable using a **variable declaration** followed by an **identifier**.

```
variableDeclaration identifierName = value;
```

## Three types of variable declarations

1. `var`
2. `let`
3. `const`

## Examples

```javascript
var city = "Bhubaneswar";
let age = 23;
const pi = 3.14;
```

> 💡 **Quick tip:** Use `const` by default, use `let` when you need to change the value, and avoid `var` in modern code.
