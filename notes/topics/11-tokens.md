# Tokens

> A **token** is the smallest unit of a programming language.

## 1. Keywords

- Predefined words which have some **special meaning**, understood by JS.
- Always in **lowercase**.
- Examples: `var`, `let`, `const`, `function`, `if`, `else`, `for`.

## 2. Identifiers

- Names provided to any **variable, class, function or method**.
- **Rules:**
  - It cannot start with a number, but can have numbers in between.
  - It cannot be a keyword.
  - It cannot have any special characters other than `$` and `_`.
  - It cannot contain a space in between.

**Valid examples:** `name`, `studentName`, `_temp`, `$price`, `a1b2`
**Invalid examples:** `1name`, `my name`, `class`, `my-name`

## 3. Literals

- **Data provided by the user** — the actual values written in code.
- Examples: `10`, `3.14`, `"hello"`, `true`, `null`
