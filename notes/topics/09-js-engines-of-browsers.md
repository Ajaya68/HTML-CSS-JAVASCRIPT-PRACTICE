# JS Engines of Different Browsers

Different browsers use different JavaScript engines:

| Browser      | JS Engine         |
|--------------|-------------------|
| Chrome       | V8                |
| Firefox      | SpiderMonkey      |
| Safari       | JavaScriptCore (Nitro) |
| Edge (older) | Chakra            |
| Node.js      | V8                |

> 📌 **Note:** Chrome and Node.js share the same engine — **V8**. That is one reason Node.js is so fast.
