# What is JavaScript?

JavaScript is a **high-level programming language** which is used to create **interactive web pages**.

## Key Points

- It is the **only language understood by the browser**.
- JavaScript is a **scripting language**.
- It is the language you can use at the **browser and server sides**.
- It is the most commonly used and popular language right now.
- A lot of frameworks and libraries are based on JavaScript. It can be used for both **frontend and backend**.

| Side     | Frameworks & Libraries        |
| -------- | ----------------------------- |
| Frontend | React JS, Angular JS, Next JS |
| Backend  | Node JS, Express JS           |

> 📌 **In simple words:** JavaScript makes web pages interactive — clicking buttons, validating forms, showing animations, and talking to servers.
