# Versions of ECMAScript

ECMAScript is the **standard** on which JavaScript is based. It is managed by the **European Computer Manufacturers Association (ECMA)**.

The most famous and important version is **ES6 (ECMAScript 2015)** because it added many modern features that we use every day:

- `let` and `const`
- Arrow functions
- Classes
- Template literals
- Destructuring
- Spread and rest operators
- `Map` and `Set`
- Modules

> 📌 **Note:** The terms *JavaScript* and *ECMAScript* are often used interchangeably. ECMAScript is the specification; JavaScript is the implementation.
