# Characteristics of JavaScript

JavaScript has the following characteristics:

1. **Client-side Scripting Language** — runs in the browser.
2. **Dynamically Typed Language** — variable types are decided at runtime.
3. **High Level Language** — easy for humans to read and write.
4. **Weakly / Loosely Typed Language** — automatic type conversion happens.
5. **Interpreted Language / Synchronous / Single Threaded** — executes line by line, one task at a time.
6. **Object Based Language** — everything works with objects.
7. **Object Oriented Programming Language** — supports OOP concepts.
8. **Light-weight Language** — small and fast.

> 💡 **Key idea:** JavaScript is single-threaded and synchronous by default, but it can handle async tasks (like Promises, `async/await`) to avoid blocking.
